── 4. Cloudflare — Charbel action required ─────────────────────────────────

BLOCKER: An active Cloudflare "crawler-cache" Worker on the bidvex.com
zone intercepts Googlebot requests BEFORE they reach the origin. Until
this Worker is neutralized, none of the SEO work in iter354-iter359
becomes visible to Google.

Action:
  1. Log in to https://dash.cloudflare.com
  2. Select `bidvex.com` zone → Workers Routes
  3. Delete or disable the `crawler-cache` route
  4. Purge the Cloudflare cache (Caching → Configuration → Purge Everything)
  5. Wait 5 minutes for propagation
  6. Test: curl -A "Googlebot" https://www.bidvex.com/en/marketplace
     Expected: full SSR HTML with JSON-LD blocks visible in the response.

After the Worker is disabled, submit the sitemap index to GSC (step 2
above) — Google typically issues its first crawl within 24-48 hours.

── 6. Post-Deploy Verification (curl commands) ─────────────────────────────

Test each URL AFTER Cloudflare Worker is disabled:

  # NewsArticle JSON-LD present
  curl -s https://www.bidvex.com/press/quebec-launch | grep -c NewsArticle
  # Expected: 1 (or higher)

  # French page returns FR content
  curl -s https://www.bidvex.com/presse/lancement-quebec | grep -c "Fondateur"
  # Expected: >= 2

  curl -s https://www.bidvex.com/sitemap-static.xml | grep -c 'xhtml:link'
  # Expected: >= 60 (30 EN + 30 FR pages * 3 alternates each = 180+ tags)

  # Root Accept-Language redirect works for FR

  curl -sI -H "Accept-Language: en-US" https://www.bidvex.com/
  # Expected: HTTP/2 302 + Location: /en/
