## Recipient safety

Every dispatch is routed through a wrapper installed in
`billing_visual_qa_delivery.py::install_safety_wrapper()` that:

* forces the `to_email` argument to `charbel911@gmail.com` regardless of the
  original recipient the flow would have used;
* prefixes every subject with `[TEST/PREVIEW]`;
* injects a top-of-body `⚠️ TEST / PREVIEW — VISUAL QA COPY ONLY` banner into
  every HTML body;
* stamps every message with SendGrid categories `["iter482","visual-qa","TEST-PREVIEW"]`;
* records the original recipient in a `qa_original_to` custom-arg so the
  intent-vs-delivery is auditable in SendGrid Activity Feed;
* uses stub DB objects for `deposit_refunded_email`, `charge_confirmation_email`,
  `payout_confirmation_email`, and `dispatch_variance_notification` so no
  MongoDB row is created, mutated, or read.
